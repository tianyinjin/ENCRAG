The episodic memory construct suggests that there is a single mental faculty
responsible for very different kinds and uses of memory such as impersonal modal
memory and affective amodal memory. There is no such single mental faculty, how-
ever,andconsequently,theepisodicmemoryconstructobscuresmorethanitclarifies.
There is no such thing as episodic memory.
