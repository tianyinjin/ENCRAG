Créer un disque de réinitialisation de mot
de passe pour un compte local
(+ Vidéo)
Lorsque vous utilisez un compte local1 dans Windows 10,
22
vous avez la possibilité de créer un disque de réinitialisation
de mot de passe à l’aide d’une clé USB qui vous permettra
de réinitialiser votre mot de passe en cas d’oubli. Nous vous
conseillons de créer cet outil dès que possible, n’attendez
pas d’avoir oublié votre mot de passe, car il sera trop tard.
Tout d’abord, connectez à votre ordinateur une clé USB
vide. Dans la zone de recherche2 sur la barre des tâches,
saisissez « panneau de configuration » 11 , puis ouvrez le
Panneau de configuration 22 :
11
Dans le panneau de configuration, choisissez Comptes d’utilisateurs 33, puis cliquez
à nouveau sur Comptes d’utilisateurs 44 :
33
44
Dans la barre de menu latérale,
choisissez Créer un disque de
réinitialisation du mot de passe 55 :
55
1 Cette méthode ne s’applique pas aux comptes Microsoft, car le mot de passe d’un compte
Microsoft n’est pas stockés sur votre ordinateur, mais sur un serveur distant.
2 Si la zone de recherche est invisible, regarder le tutoriel «Afficher les extensions des fichiers ».
