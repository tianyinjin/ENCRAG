Afficher les extensions des fichiers
L’absence d’extension peut tromper sur la véritable nature d’un fichier, par exemple, un
fichier image peut en réalité être un exécutable contenant un programme malveillant.
Il suffit pour cela de nommer un fichier image.jpg.exe : si l’extension .exe est masquée,
vous ne verrez que image.jpg en pensant qu’il s’agit juste d’une image1. Lorsque vous
allez l’ouvrir, c’est l’exécution du code malveillant que vous allez lancer.
