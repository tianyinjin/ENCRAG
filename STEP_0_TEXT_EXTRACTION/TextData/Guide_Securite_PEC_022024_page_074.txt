Utilisation
Lors de la première utilisation, il est nécessaire de créer une base de données qui va
regrouper tous vos mots de passe dans un seul fichier. Pour cela, cliquez sur l’icône
en haut à gauche 11 , puis sur le bouton OK 22 :
11
22
Choisissez l’emplacement et le nom de votre base (évitez les noms qui permettent de
savoir qu’il s’agit d’une base contenant les mots de passe), puis cliquez sur Enregistrer
33. Une nouvelle fenêtre s’ouvre, qui vous invite à créer le mot de passe principal.
C’est le seul mot de passe que vous devez retenir, car il vous permettra d’accéder à
tous vos mots de passe. L’indicateur de complexité du mot de passe permet d’évaluer
le risque de sécurité1. Plus l’indicateur tend vers le vert, plus le mot de passe est
robuste 44. Une fois le mot de passe choisi, cliquez sur OK 55 :
44
33
55
1 Suivez les conseils de la fiche « Mots de passe ».
