1
Introduction
1.1
Product description
This product is a water coil with a frost protection sensor de-
signed for installation inside the SAVE VSR 700.
1.2
Intended use
The product is used to either increase or decrease the tem-
perature of the supply air.
The product must replace the internal electrical heater.
The product must be connected to the condensation drain-
age pipe when used as a cooler.

3
Installation
3.1
To do before the installation
of the product
•
Examine the packaging for transportation damage and re-
move the packaging from the product carefully.
•
Examine the product and all components for damage.
•
Make sure that the information on the name plate agrees
with the order confirmation.
•
Make sure that you have the necessary installation
accessories.
•
Make sure that the installation location is clean and dry,
for full safety during electrical work.
•
Make sure that the installation location has the access to
the drainage system.
•
Make sure to disconnect the SAVE VSR 700 from the
power supply.
3.2
To install the product
Caution
Use protective gloves during installation
and maintenance. Sharp edges can
cause injury.
Caution
Make sure the rotating parts have come
to a complete standstill before you do the
maintenance.
1
Disconnect the SAVE VSR 700 from the power supply.
2
Remove the door.
3
Remove the internal electrical heater cover.
4
Disconnect the fan cables. The cables can be found next
to the fan.
Carefully disconnect the pressure measurement tube.
Pull out the fan towards you. Some force may be needed.

3.3
To configure
1.
Go to Service menu.
2.
Enter the password (default 1111).
3.
Set the heater type Components Ø Heater Ø Water.
Set the actuator voltage type.
4.
If the product has an internal electric heater, set the elec-
tric heater control as inactive. Go to Service Ø Output
Ø ANALOG Ø TRIAC OUTPUT Ø Inactive Output.
5.
Go to Service Ø Output Ø ANALOG. Select the ana-
logue output to which the actuator is connected, set the
value to Y1 Heating.
6.
Configure the frost protection sensor (FPT). Go to Serv-
ice Ø Input Ø ANALOG. Select the analogue input to
which the sensor is connected, set the value to Frost
Protection Temp. Sensor (FPT).
