LES PREVISIBLES 
  
Les mots qui se trouvent dans cette catégorie ont deux sens. LE SENS LE PLUS LOGIQUE EST LE PLUS 
RARE. 
  
acceptable (adj) 
 
agréable, bienvenu, qui fait plaisir ; acceptable. 
to accomodate 
 
loger, accueillir, recevoir ; s’accommoder. 
anxious (adj)  
 
tenir beaucoup à faire qqch. 
anxiety  
 
 
désir, impatience ; anxiété. 
an apology 
 
 
une excuse, une justification; une apologie 
to apologize 
 
 
s’excuser, regretter. 
  
a camera 
 
 
un appareil photo; une camera de cinema. 
comfort 
 
 
la consolation, le réconfort ; le confort. 
a conference  
 
un congrès, un colloque ; une conférence. 
a crab  
 
 
morpion ; pomme sauvage ; crabe. 
to cry  
 
 
pleurer ; pousser un cri, des cris. 
  
a date  
 
 
un rendez-vous, un « rancard »; une datte ; une date. 
a delay  
 
 
un retard ; un délai. 
a demonstration 
 
« une manif » ; une démonstration. 
a detail 
un détachement militaire ; des coordonnées personnelles ; un détail. 
a diet 
un régime (alimentaire ou amincissant) ; une diète. 
discreet (adj) 
prudent/sage ; discret, sobre. 
a disgrace 
 
 
une honte, un déshonneur ; une disgrâce. 
to dispose of  
 
se débarasser de, jeter, tuer qqun; vendre; disposer de. 
distraction 
 
la folie, la démence, la confusion ; l’interruption (travail) ; la distraction. 
drama 
 
le théâtre ; le drame. 
dramatic (adj)  
spectaculaire, théâtral ; dramatique. 
a drug 
 
un médicament, un produit pharmaceutique ; une drogue. 
a drogue = une ancre flottante, une ancre de cape. 
  
eligible (adj) 
 
qui a le droit à, qui remplit les conditions pour ; acceptable ; éligible. 
to endure 
 
durer, demeurer, rester ; endurer. 
evidence (inv)  
preuves, témoignages, indices (justice) ; l’évidence. 
  
fatigue 
 
corvée (militaire) ; fatigue. 
 to be on fatigue = être de corvée 
 fatigues / fatigue dress = tenue de corvée, treillis. 
a fault 
 
un défaut, une erreur ; une défaillance (mécanique) ; une faille (géologique) ; 
une faute. 
a figure 
 
une silhouette, un personnage, une forme ; une statistique, un chiffre ; une 
figure. 
a film 
 
pellicule (photo) ; mince couche, pellicule (poussière) ; voile (brume) ; film. 
a form 
 
un formulaire, un imprimé ; une classe (école) ; une forme. 
it is good/bad form to…= ça se fait/ ne se fait pas de… 
  
genial (adj) 
 
cordial, aimable, sympathique ; clément (temps) ; génial. 
  
habit 
 
tenue, habit (de cérémonie, de religieux) ; habitude. 
a hazard 
 
un risque, un danger ; hasard. 
a holdup 
 
retard, embouteillage, bouchon ; un hold-up. 
  
impatient (adj)  
intolérant ; impatient. 
 
impression 
 
imitation (comique) ; impression, empreinte. 
improbable (adj) 
invraisemblable, peu crédible ; improbable. 
an indemnity  
une garantie, une assurance ; une indemnité. 
indifferent (adj) 
médiocre, quelconque ; indifférent, neutre, impartial. 
industry 
 
zèle, application ; industrie. 
intelligence (inv) 
renseignement(s), information(s) ; intelligence. 
military intelligence = service de renseignements de l’armée. 
an intelligence agent = un agent secret.
