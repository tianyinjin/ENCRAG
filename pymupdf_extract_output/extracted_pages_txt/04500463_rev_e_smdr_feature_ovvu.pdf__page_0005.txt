SMDR Feature Overview 
 
5
Capturing SMDR data over Ethernet 
The NSP (Network Services Processor) can be used to output SMDR data over an IP network; and a Telnet 
connection can be made to the NSP, using port xx003 (default is 59003), to capture this data. For more 
information, see NSP Installation Made Simple (ESI # 0450-0669).
