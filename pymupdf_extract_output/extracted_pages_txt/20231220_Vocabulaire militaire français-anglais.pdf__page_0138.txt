108 "As You Were" : Military command or order meaning to disregard the previous partial command or order and 
return to the most recent formal command or order. S’utilise par exemple lorsqu’une autorité entre dans une salle 
dont les occupants se lèvent pour se mettre au garde à vous ; signifie alors « ne bougez pas ! ». 
109 To wheel = tourner ; pivoter sur ses talons = to pivot on one's heels 
110 Former les faisceaux = to pile arms ; rompre les faisceaux = to unpile arms. 
111 Se tenir sur une ligne (plusieurs personnes sur une ligne) = to stand in a row.
