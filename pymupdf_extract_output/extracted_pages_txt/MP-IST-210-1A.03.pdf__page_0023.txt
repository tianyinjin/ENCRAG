3.2.3 
Visualization and Analysis 
Visualization and analysis involve a powerful engine that evaluates various performance metrics, including 
mission-specific criteria, object detection/tracking accuracy, localization accuracy, and maneuver precision. 
It translates these technical metrics into standardized AI System Quality Indices (ASQI), providing 
comparable and interpretable grades across different capability categories.  
In order to be able to do different types of analysis on the data generated as outlined in section 3.2.1, e.g. 
coverage analysis, all relevant metadata is also collected, which can include drone positions, headings, 
movement speed, as well as data on ambient conditions such as fog or rain settings. Results are presented on 
a front-end dashboard for clear decision-making but are also available as data artefacts for individual data 
analysis projects. 
3.2.4 
System Architecture, Result Storage and Retrieval 
The simulation platform is designed with a flexible architecture supporting both air-gapped on-premises 
deployment for sensitive projects, and cloud-based parallel processing for high-throughput analysis, as well 
as single-compute-instance use cases, and parallelized use cases for high throughput. Results are stored in a 
tamper-proof environment together with extensive documentation artefacts detailing the conditions and 
parameters of test scenarios, in relation to the data generated for each case.
