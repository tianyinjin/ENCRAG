our reasoning, we construct a binomial data distribution for the object detection system, i.e. it either detected 
everything in an image/video correctly or it did not and further assume a perfect result reflecting that the 
object detection system did achieve its main objective in the cases we observed. We can then calculate a 
confidence interval for the pass rate, which reflects the uncertainty for similar performance to be observed in 
new videos from the same combination of parameters, even if empirically a system did perform perfectly for 
the known examples. This uncertainty is statistically reflected by the width of the confidence interval, which 
we generate using Wilson’s method for a one-sided confidence test for a 95% threshold, as implemented in 
the popular data science library scipy through the method BinomTestResult.proportion_ci. Examining the 
confidence interval (ci_low) in each scenario gives us an indication of where the test data may need to be 
further augmented, especially if certain scenarios are of higher mission importance.
