The episodic memory construct suggests that there is a single mental faculty
responsible for very diﬀerent kinds and uses of memory such as impersonal modal
memory and aﬀective amodal memory. There is no such single mental faculty, how-
ever, and consequently, the episodic memory construct obscures more than it clariﬁes.
There is no such thing as episodic memory.
